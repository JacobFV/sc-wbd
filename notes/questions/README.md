- `idea` — noticed, not thought through. Most notes start and stay here.
- `open` — someone has written what would answer it.
- `answered` — link the `findings/` note that measured it.
- `rejected` — one line on why. **Never delete an idea for being bad**; the next agent will
  otherwise have it again.

A question that is blocked on something external carries `blocked_on:` in its frontmatter, so the
index can list it without anyone maintaining a second list.
